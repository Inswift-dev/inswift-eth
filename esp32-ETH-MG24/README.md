# ESP32 + EFR32MG24 firmware resources

We provide ongoing firmware updates and iterative improvements to refine the product. For typical use, **online (OTA) upgrades** are sufficient and recommended.

If you encounter exceptional circumstances that require a **local firmware upgrade**, please **reach out through official channels** to obtain release packages. Always **verify** images (checksums/signatures where provided) before flashing, to minimize the risk of failed upgrades or unstable device behavior.
