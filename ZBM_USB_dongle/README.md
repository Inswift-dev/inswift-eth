# ZBM USB Dongle

This directory is the entry point for **ZBM-MG21 / ZBM-MG24** and other Silicon Labs-based USB dongle firmware resources.

For the flashing tool, prebuilt firmware images, and detailed usage guides, please visit:

[![Inswift Silabs Flasher](https://img.shields.io/badge/Inswift_Silabs_Flasher-Firmware_Flasher-blue)](https://github.com/Inswift-dev/inswift-silabs-flasher)

**Direct link**: [https://github.com/Inswift-dev/inswift-silabs-flasher](https://github.com/Inswift-dev/inswift-silabs-flasher)

---

*Inswift Silabs Flasher* is a Windows GUI tool for flashing Silicon Labs-based wireless chips. It supports Zigbee NCP, Zigbee Router, OpenThread RCP, and Multi-PAN CPC protocols, and is optimized for Inswift USB dongle products.
